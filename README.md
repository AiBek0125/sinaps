# Синапс — дружелюбный PWA-ассистент учителя для школьников 12–17 лет

«Синапс» помогает на уроках по **биологии (7–9 класс)**, **физике (10–11 класс)**, **химии (8–9 класс)** и **истории (облик и одежда по векам)**. Приложение работает **без VPN**, ищет ответы на проверенных российских образовательных платформах и в энциклопедиях, устанавливается как PWA и поддерживает 22+ интерактивные схемы офлайн через кнопку **«5 тем предмета»**.

---

## Возможности ассистента (как «Алиса» для школьных уроков и исследований)
- **Стоп-слово «Синапс» в любой момент**:
  - Если робот ищет, думает или говорит, слово «Синапс» сразу обрывает речь (`speechSynthesis.cancel`) и отменяет незавершённый запрос к ИИ; устаревший ответ не появляется на экране.
  - Робот поворачивает голову к источнику голоса (по стерео-микрофону; на моно-микрофоне смотрит прямо) и переходит в «Слушаю…» — можно сразу задавать новый вопрос.
  - «Синапс, стоп» / «Синапс, хватит» останавливает робота полностью. Одинаковая фраза «Синапс» не запускается дважды за 2 секунды, а разные фразы проходят всегда.
  - Фразу можно начинать и с «окей»: «Окей, Синапс, как работает митоз».
  - Рекомендуется использовать наушники с микрофоном: иначе голос робота из динамиков может попасть в микрофон и быть принят за команду (приложение пытается отфильтровать собственную речь, но полностью это не исключает).
- **Прямой ответ сразу по сути + два уровня глубины**: Синапс не тратит время на вводные фразы вроде «Вот что нашёл...». На первый запрос он отвечает кратко по самой сути, а когда ученик просит *«подробнее»*, *«разложи по шагам»*, *«дальше»* или нажимает **«🔍 Расскажи подробнее» / «🧪 Практика / опыт»** — раскрывает механизм детально и предлагает практическое исследование.
- **Живой поиск по проверенным российским платформам (`search.js`)**: при каждом вопросе Синапс ищет факты в белом списке источников — **Большая российская энциклопедия (`bigenc.ru`)**, **РУВИКИ (`ru.ruwiki.ru`)**, **Фоксфорд (`foxford.ru`)**, **InternetUrok (`interneturok.ru`)**, **ЯКласс (`yaklass.ru`)**, **РЭШ (`resh.edu.ru`)**, **Skysmart**, **Элементы науки**, **ПостНаука**, **Arzamas**, **Культура.РФ**, **История.РФ**, **Русская Википедия** — и прикрепляет кликабельные ссылки под ответом.
- **Один мягкий женский голос**: Синапс выбирает лучший женский русский голос системы автоматически (Google русский, Milena, Irina и др.), мужские голоса исключены. Речь делится на смысловые части с естественными паузами и лёгкими колебаниями интонации, а ударное «е» в школьных терминах помечается «ё» (пищевод → пищёвод, клетка → клётка).
- **Плавные физические графики**: ползунки силы, напряжения, сопротивления, расстояния до линзы, сдвига фаз и момента времени задают цель, а картинка плавно её догоняет без пересборки и мерцания. Переключение режимов (равномерное/равноускоренное, собирающая/рассеивающая линза) тоже плавное.
- **Новые темы биологии и детализированные анимации**: добавлены интерактивные схемы **«Строение семян»** (двудольное/однодольное с подписями) и **«Рост и прорастание семян»** (этапы по дням + опыт с водой, теплом и кислородом), а также детализированы схемы клетки, митоза, одноклеточных, цепей с амперметром/вольтметром/ключом, оптики, атома и реакций.
- **Работает без VPN**:
  - Убраны внешние CDN (`jsdelivr.net`, `cdn.plot.ly`, Google Fonts) — **KaTeX** и интерактивные SVG-графики встроены прямо в сборку.
  - Запросы к Gemini идут через серверный прокси `/api/ask`, а резервный провайдер **DeepSeek** и поиск по **РУВИКИ / Википедии** работают из России без VPN.
  - Есть автономный сервер `server.js` для запуска локально или на любом российском облаке/VPS (Timeweb, Amvera, Selectel, Yandex Cloud) без привязки к зарубежным хостингам.

## 1. Получить бесплатный ключ Google Gemini
1. Перейдите на [aistudio.google.com](https://aistudio.google.com) и войдите в аккаунт Google.
2. Нажмите **Get API Key** → **Create API Key**.
3. Скопируйте полученный ключ (создаётся бесплатно, банковская карта не требуется).

> ⚠️ Никогда не вставляйте API-ключ в клиентский код! В приложении нет поля ввода ключа — он хранится только на сервере в переменных окружения (`GEMINI_API_KEY` / `DEEPSEEK_API_KEY`).

---

## 2. Деплой на Netlify или на российский хостинг (без VPN)

### Вариант А: Netlify (с зарубежным сервером для Gemini)
1. Загрузите проект на [app.netlify.com](https://app.netlify.com) или [netlify.com/drop](https://app.netlify.com/drop) (параметры описаны в `netlify.toml`).
2. В Netlify откройте **Site settings** → **Environment variables** и добавьте:
   - `GEMINI_API_KEY` — ваш ключ из Google AI Studio.
   - *(Опционально)* `DEEPSEEK_API_KEY` — ваш ключ DeepSeek.
3. Перезапустите деплой (**Deploys → Trigger deploy**).

### Вариант Б: Запуск без VPN на российском сервере или локально (`server.js`)
Если провайдер ограничивает зарубежные площадки или вы хотите разместить сайт на российском хостинге:
```bash
npm install
npm run build
DEEPSEEK_API_KEY="ваш_ключ" node server.js
```
Сервер поднимется на порту `3000` (или `PORT`), отдаст собранную статику из `dist/` и обработает `/api/ask` с поиском по российским образовательным платформам. Даже без API-ключей ИИ Синапс продолжит искать ответы в РУВИКИ и Википедии и показывать интерактивные схемы!

---

## 3. Установка PWA на рабочий стол и телефон
1. Откройте сайт в **Google Chrome**, **Яндекс Браузере** или **Microsoft Edge**.
2. В адресной строке справа нажмите значок установки (**«Установить Синапс»**) → **Установить**.
3. На рабочем столе или телефоне появится иконка «Синапс», а Service Worker (`sw.js`) закэширует все локальные ресурсы и шаблоны для работы офлайн.

---

## 4. Проверка работы
1. Нажмите **«Разрешить микрофон»** (или **«Записать 10 сек»**).
2. Произнесите командное слово: **«Синапс»** → затем вопрос: **«Как работает митоз»** (или произнесите слитно: **«Синапс, как работает митоз»**).
3. Синапс найдёт подтверждённую информацию на образовательных платформах, ответит голосом, покажет ссылки на **Проверенные источники** и запустит плавную анимацию четырёх фаз митоза (**профаза, метафаза, анафаза, телофаза**).
4. Для проверки без интернета нажмите **«5 тем предмета»** и выберите любую тему — анимации и объяснения запустятся мгновенно из кэша.

---

## 5. Опциональный резерв DeepSeek (работает в РФ без VPN)
1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com) и создайте API-ключ (при регистрации дают стартовые бесплатные токены, далее работа платная; картой РФ напрямую не оплатить — только если есть подходящая карта).
2. Добавьте `DEEPSEEK_API_KEY` в переменные окружения сервера.
3. При сбое или региональной блокировке Gemini сервер автоматически переключится на DeepSeek, либо вы можете включить чекбокс **«Использовать DeepSeek (резерв без VPN)»** в ⚙️ Настройках.

---

## 6. Лимиты Gemini Free Tier
- Бесплатный тариф Google AI Studio (`gemini-1.5-flash` / Flash-семейство) предоставляет около **10–15 запросов в минуту** и до **~1500 запросов в день** — хватает на 30+ уроков ежедневно.

---

## 7. Детская безопасность и модерация (12+)
Весь контент рассчитан на школьников 12–17 лет и защищён на всех уровнях:
1. **Клиентский фильтр речи и ввода (`ai.js`)**: стоп-слова 18+, нецензурная лексика, насилие, жестокость, политика, религия, алкоголь и наркотики блокируются *до отправки на сервер* («Давай о чём-нибудь из уроков» / «Это вне урока. Спроси учителя или родителей»).
2. **Фильтр интернет-источников (`search.js`)**: поиск ограничен строгим белым списком доверенных образовательных доменов (`TRUSTED_EDU_DOMAINS`) и проверяет каждый заголовок и фрагмент.
3. **Серверные фильтры Gemini (`api/ask.js`)**: категории `HARASSMENT`, `HATE_SPEECH`, `SEXUALLY_EXPLICIT`, `DANGEROUS_CONTENT` установлены в максимум (`BLOCK_LOW_AND_ABOVE`).
4. **Проверка картинок и схем (`history-images.js`, `ai.js`)**: любые данные `show` и результаты Wikimedia Commons дополнительно проверяются на стоп-слова перед отрисовкой.

## Структура проекта
```text
/
├── index.html          # Точка входа HTML и мета-теги PWA
├── manifest.json       # Манифест PWA (+ public/manifest.json)
├── sw.js               # Service Worker (+ public/sw.js)
├── app.js              # Контроллер триггера «Синапс» и регистрация SW
├── avatar.js           # 3D-мультяшный векторный робот «Синапс» (SVG + rAF)
├── animations.js       # 22+ шаблонов анимации, локальный KaTeX, SVG-графики, диаграммы
├── voice.js            # Живая русская озвучка (словарь «ё», speechify, интонация)
├── search.js           # Поиск по проверенным российским образовательным платформам
├── ai.js               # Модерация, каталог «5 тем предмета», клиент /api/ask
├── history-images.js   # Безопасный поиск исторических фото через Wikimedia Commons
├── api/ask.js          # Серверлес-прокси Netlify к поиску, Gemini Flash и DeepSeek
├── server.js           # Автономный сервер Node.js (для запуска без Netlify и без VPN)
├── netlify.toml        # Конфигурация сборки, функций и редиректов Netlify
└── README.md           # Инструкция по запуску, деплою без VPN и безопасности
```
